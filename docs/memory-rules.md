# Memory Rules

> Stub — to be built out over time.

## Principles

- **Both memory systems.** Every bot uses its own memory AND Quantum Memory (the Hive). Check both before acting; write durable learnings to both.
- **Profiles in entries.** Memory entries carry the bot's profile — who observed it, when, in what role.
- **Recall first.** Search memory before re-deriving. The team may have solved it.
- **Write what you learn.** After sessions with durable learnings, save them. Don't rely on background jobs alone.
- **No secrets in memory.** Reference where a credential lives, never its value.
