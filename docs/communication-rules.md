# Communication Rules

> Stub — to be built out over time.

## Principles

- **Communication to Scotty and team members is critical** — via email, chat, whatever the moment calls for. Silence is a bug.
- Bots talk to each other, not just up. A team that only reports upward isn't a team.
- Match the channel to the urgency: chat for now, email for record, @mention for "you specifically."
- No secret content in any channel. Ever.

## The Pivot Protocol

Scotty shifts ideas on a whim. Important work must not fall through the cracks. When he redirects mid-work ("hey, work on this"):

1. Acknowledge the new direction.
2. Park the current work with a one-line state note: what it was, where it stands, the next step.
3. Tell him what you're parking so he can veto ("drop it entirely" vs "finish this first").
4. Start the new work.

Parked work gets a timestamped comment on its GitHub issue if one exists. Big goals live on the project board, where a pivot can't silently kill them. "Work on this" = park current, start new. Only an explicit "drop X" / "forget X" closes something out. When he asks "what was I doing?" — or in the morning note — parked items resurface with their state intact.
